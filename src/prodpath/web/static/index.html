prodpath read-only analysis, nothing runs

From repo to production, with a price tag

Paste a public GitHub repo.
Get the AWS plan, Terraform and what it will cost.

prodpath reads your code like a careful engineer: services, ports, databases, queues, env var names. Then it proposes an architecture, writes validated Terraform and forecasts the monthly bill, including the traps that quietly inflate it.

Options

1. It reads

Shallow, read-only clone. Python and JavaScript are parsed, Dockerfiles and manifests read. Secrets are never opened, only variable names.

2. It plans

Rules, not guesses: ECS Fargate behind one load balancer, databases, caches, queues, with a reason and evidence for every piece.

3. It prices

Real AWS list prices produce a low, expected and spike month, plus ranked traps that show what can bite you.
